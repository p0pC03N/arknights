# 初识花指令
打一道花指令奇多的题越打越不对劲，仔细一瞧发现原来我对花指令处理全是错的（无脑nop一切跳转地址+1，一学正确处理要把自己气笑了，怪不得花越去越多）。所以先来细细总结一番。花指令集听起来颇有古韵。
## LV1
塞垃圾数据骗IDA当成指令

+ 垃圾字节
  ```c
  __asm{
    jmp label1
    db junkcode
    label1:    
    }
    ```
    nop掉垃圾字节

    有一些IDA汇编表现出莫名出现的字节，（讲实话以前一直觉得这种断掉我函数块的字节很奇怪，现在才知道是故意的）；

    有一些IDA汇编表现的是正常指令，（通常因为是垃圾字节所以反汇编出jz near ptr loc_401868+1,观察机器码看其跳过的字节大小相应去nop，也不一定，要注意观察是不是真实指令）

    总的来说**如果出现绝对不可能执行的部分则需nop**（✋😭🤚也不一定，具体问题具体分析，要配合的看上下指令的逻辑，处理方式也很丰富）
+ 互补跳转花指令
  ```c
    #include<cstdio>
    int main() {
    __asm {
        jz s;
        jnz s; // 互补跳转，必然跳转到 s
        _emit 0xE9; // 垃圾数据（jmp imm32 的操作码）s:
    }
    printf("hello world!\n");
    return 0;
    }
    ```
    + jz s; —— 零标志位为 1 时跳转（Jump if Zero）
    + jnz s; —— 零标志位为 0 时跳转（Jump if Not Zero）

  必然跳转到目标标签，IDA则会把0xE9当作下一条指令起始，nop掉跳转之间的垃圾数据
## LV2
永真永假式

+ 
  ```c
  __asm{
    push ebx
    xor ebx,ebx
    test ebx,ebx
    jnz label1
    jz label2
  label1:
    _emit junkcode
  label2:
    pop ebx
  }
  __asm{
    clc
    jnc label1     
    _emit junkcode ; 
    label1:
  }
  ```
  第一段：

    + xor ebx, ebx：把 EBX 置 0，并且会设置标志位：ZF=1（结果为 0）

    + test ebx, ebx：相当于 ebx & ebx，结果还是 0，所以 ZF 仍然 = 1

  所以到跳转时：

    + jnz label1 = Jump if Not Zero = ZF==0 才跳
    但现在 ZF=1 → 永远不跳

    + jz label2 = Jump if Zero = ZF==1 才跳
    现在 ZF=1 → 永远跳到 label2

  第二段：

    + clc 是 清 CF（Carry Flag）
    + jnc 判断的是CF（jump if not carry）
  
  中间 _emit junkcode 永远不会执行，但静态反汇编仍把它当成代码。用nop替换false分支中的垃圾数据，或直接删除该分支。

（其实这些汇编我看不懂，所以这里我打算去学学汇编，刚好文章后面的花我没怎么接触过）

## LV?
不知如何归类的花指令
### 3CE9
cmp al, 0E9h

字节 E9 在反汇编里非常“敏感”：从某个地址开始看到 E9 xx xx xx xx，反汇编器会立刻认为这是一个远跳转，CFG 会分叉

如果 cmp al, 0E9h 的标志位没有被后续任何指令使用（例如后面没有 jcc/setcc/cmov/adc/sbb 依赖它），那它几乎可以判定为junk，或者只是为了在字节流里埋一个 E9 来配合别处的错位解码


特征码为3C E9， 将该指令patch为ud2指令，其后的4个字节patch为nop指令。

### Skill2
难以判断是否跳转的花指令
```arm

.text:0000000000401ACD 55                                push    rbp
.text:0000000000401ACE 48 89 E5                          mov     rbp, rsp
.text:0000000000401AD1 48 81 EC 40 00 00                 sub     rsp, 40h
.text:0000000000401AD1 00
.text:0000000000401AD8 48 89 4D 10                       mov     [rbp+10h], rcx
.text:0000000000401ADC B8 D2 05 03 00                    mov     eax, 305D2h
.text:0000000000401AE1 49 89 C2                          mov     r10, rax
.text:0000000000401AE4 4C 89 D1                          mov     rcx, r10
.text:0000000000401AE7 E8 91 15 01 00                    call    loc_41307D
.text:0000000000401AEC 0F BE 0D 62 15 01                 movsx   ecx, cs:byte_413055
.text:0000000000401AEC 00
.text:0000000000401AF3 39 C8                             cmp     eax, ecx
.text:0000000000401AF5 0F 8D 06 00 00 00                 jge     loc_401B01

.text:0000000000401AFF 00                                db 0
.text:0000000000401B00 00                                db 0
.text:0000000000401B01                   ; ---------------------------------------------------------------------------
.text:0000000000401B01
.text:0000000000401B01                   loc_401B01:                             ; CODE XREF: .text:0000000000401AF5↑j
.text:0000000000401B01 0F BE 05 4D 15 01                 movsx   eax, cs:byte_413055
.text:0000000000401B01 00
.text:0000000000401B08 81 F8 33 02 00 00                 cmp     eax, 233h
.text:0000000000401B0E 0F 86 16 00 00 00                 jbe     loc_401B2A
.text:0000000000401B14 B8 70 03 00 00                    mov     eax, 370h
.text:0000000000401B19 49 89 C2                          mov     r10, rax
.text:0000000000401B1C 4C 89 D1                          mov     rcx, r10
.text:0000000000401B1F E8 3B 15 01 00                    call    sub_41305F
.text:0000000000401B24 3C E9                             cmp     al, 0E9h
.text:0000000000401B26 B3 01                             mov     bl, 1
```
首先因为执行到0x401AFB处，程序一定会崩溃（add cl, ch，fadd qword ptr [rcx]是和前文基本无关的古怪指令），所以这个jbe     loc_401B2A一定要处理。

无法确定是否一定会跳转，所以将跳过的6个字节前2个patch为ud2指令，后4个指令patch为nop指令。不影响正常路径，让错误路径更显式（进来就 UD2），让静态反汇编更干净。

也可以直接改成jmp的，只是这种处理最稳妥保守。

### Skill3 
手修法
将要跳转部分函数u处理，垃圾字节一目了然，再在正常程序p(c)。

无法判断是否跳转时，在函数下断点，右键set IP,执行程序观察其是否跳转。
